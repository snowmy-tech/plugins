# Cost

Analyze AWS costs, identify savings, manage budgets, and evaluate commitments and right-sizing recommendations.

## Included skills

- **aws-billing-and-cost-management** — Analyze AWS costs, find savings, manage budgets, evaluate Savings Plans and Reserved Instances, right-size EC2/Lambda/RDS/EBS with Compute Optimizer, look up service pricing, query CUR with Athena, detect cost… ([procedure](skills/aws-billing-and-cost-management/SKILL.md))

## Requirements and authentication

Use the AWS CLI or SDK credential provider chain named by the selected skill. Authentication occurs on use; installing this plugin does not sign in or store credentials.

Commands that create, update, deploy, or delete AWS resources require the user’s explicit task authorization.
