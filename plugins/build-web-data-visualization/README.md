# Web Visualization

Design, critique, implement, test, and export web data visualizations in Codex.

Start with the [data visualization router](skills/data-visualization/SKILL.md). It classifies the request and selects only the relevant specialist skill instead of loading every visualization workflow.

## Capability areas

- Visualization strategy, critique, chart selection, maps, dashboards, and scrollytelling.
- D3, SVG, Canvas, WebGL, animation, interaction, accessibility, and responsive layout.
- Testing, export, shareable state, reports, slides, mobile views, Gantt, and UML workflows.

## Runtime

The selected specialist skill declares its browser or JavaScript requirements. Installing this plugin does not install packages, publish output, or authenticate to external services.
